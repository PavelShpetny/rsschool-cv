## Code Example

Solution to the [Calculate BMI](https://www.codewars.com/kata/57a429e253ba3381850000fb/javascript):

```javascript
function bmi(weight, height) {
  const bmiValue = weight / (height * height);

  if (bmiValue <= 18.5) {
    return 'Underweight';
  }

  if (bmiValue <= 25) {
    return 'Normal';
  }

  if (bmiValue <= 30) {
    return 'Overweight';
  }

  return 'Obese';
}
```
